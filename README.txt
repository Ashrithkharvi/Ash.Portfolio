ASHRITH — SKY BLUE CONTENT CREATOR PORTFOLIO

1. Open index.html to preview.
2. Add your own MP4 files to the videos folder:
   video1.mp4, video2.mp4, video3.mp4, video4.mp4
3. Edit index.html: search for your-email@example.com and replace with your real email.
4. Optional: edit video titles and descriptions directly in index.html.
5. The beach photo is loaded from Unsplash online. Internet is needed to display it.
   Replace the background URL in CSS with your own licensed photo if desired.

FREE DEPLOYMENT ON GITHUB PAGES
1. Sign up at https://github.com
2. Create a public repository named ashrith-portfolio.
3. Upload index.html AND the videos folder (with your MP4 files).
4. Go to Settings > Pages > Build and deployment.
5. Choose Deploy from a branch, branch main, folder /(root), Save.
6. Wait for the Pages URL to appear.
7. Website URL: https://YOUR-GITHUB-USERNAME.github.io/ashrith-portfolio/

IMPORTANT: GitHub browser upload limit is 25 MiB per file; for larger video files,
upload optimized smaller MP4s or host videos on YouTube/Vimeo and embed them.
Large video files are not ideal for GitHub Pages.
